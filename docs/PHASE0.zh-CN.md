# Phase 0：真机可行性验证指南

[English](PHASE0.md) · **中文**

> **结论（2026-11-19，nubia NX733J，Android 15）：** 包名 `com.ubercab.driver`；订单弹窗出现时 Uber 把界面从无障碍树中隐藏（只剩地图），所以必须走 OCR。弹窗文字：`CA$5.50` / `including estimated tip` / `15 min (1.3 km) total` / `Accept`，价格也可能是整数（`CA$6`）。Uber 在后台时，订单卡片是一个读不到内容（root 为 null）的大窗口，弹在其他应用上方。OCR 在两种情况下都已验证可用。

目标：拿到**至少一张 Uber Driver 真实订单弹窗**的结构化文字，确认报价、距离、时间能否从无障碍节点读到；读不到就确认必须走 OCR。

> 所有操作请在**停车状态**下进行。

## 方法 A：用 FKUB 自带的快照工具（推荐）

1. 安装 FKUB，开启无障碍服务（见 README）。
2. 打开「调试」页，点 **开始抓取**。
3. 切到 Uber Driver 正常上线等单。只要 Uber 画面上的文字有变化（包括订单弹窗出现、倒计时变化、弹窗消失），就会自动保存一份快照，最快每秒一份；只是地图移动不会重复保存。屏幕左上角的红色小标记「● 抓取中 N」显示已保存的份数。
4. 收到一两个订单弹窗后，回到 FKUB「调试」页点 **结束抓取**，会自动打包成一个 zip。
5. 在「抓取记录」里点 **分享 zip** 发给开发者（或上传到项目里）。点「看最后一份」可以直接看快照里的文字：能看到 `"$9.00"`、`"29.9 km"`、`"42 min"` 这类文字，说明节点可读；只看到空白或地图，说明需要 OCR。
6. 每个会话最多 1000 份，到上限会自动结束。分享前可以检查一下，里面可能有商家名或地址。

其他方式：「10 秒后抓取」单份；开启调试模式后点系统无障碍按钮抓取单份；开启调试模式 + 自动快照。

快照包含：每个窗口的类型 / 包名 / 位置，以及目标应用窗口的完整控件树（class、id、text、contentDescription、bounds、clickable）。截图默认不保存，可在调试页开启「快照附带截图」。

## 方法 B：用 GKD 抓快照

1. 安装 GKD（https://gkd.li），按提示开启无障碍和悬浮窗权限。
2. GKD 设置 → 高级设置 → 开启**快照**相关选项（如“截屏快照”/“悬浮窗按钮”，以当前版本为准，说明见 https://gkd.li/guide/snapshot ）。
3. 在 Uber Driver 弹出订单时，点 GKD 悬浮按钮（或按其设置的截屏快照方式）保存快照。
4. GKD 里「快照记录」→ 选中 → 分享 / 导出 zip（包含截图和节点树 JSON）。
5. 把 zip 交给开发者。

注意：GKD 和 FKUB 同时开着无障碍服务没有问题，但验证完可以关掉 GKD。

## 需要从快照里确认的事项

| 项目 | 记录 |
|---|---|
| Uber Driver 包名（预期 `com.ubercab.driver`） | |
| 订单弹窗是独立窗口还是主窗口的一部分（windowType） | |
| 报价文字原样（如 `$9.00`、`CA$9.00`） | |
| 报价旁是否还有其他金额（加价、小费说明等） | |
| 距离是总距离，还是分段（取货 + 送达） | |
| 时间是总时长，还是分段 / 含“X min away” | |
| 接单按钮文字（如 `Accept` / `Match`） | |
| 是否有稳定的 view id（`viewIdResourceName`） | |
| 多点配送如何显示 | |
| 终点文字是否可读（Phase 2 城外判断用） | |
| 结论：节点可读 / 需要 OCR | |

## 拿到快照后怎么改

1. 把快照里的文字逐行粘到 FKUB「模拟」页的 *模拟屏幕文字*，看适配器输出是否正确。
2. 在 `core/src/main/kotlin/com/offerpilot/core/parser/UberDriverAdapter.kt` 的 `UberAdapterConfig` 中按真实文字调整关键字；如果距离是分段显示且确认应相加，打开 `sumLegsWhenNoTotal`。
3. 把真实快照的文字做成单元测试（去掉地址等隐私信息），放到 `core/src/test`。
4. 验证无误后把 `verifiedOnRealDevice` 设为 `true`。
5. 节点读不到时走 OCR（已实现：`app/.../capture/ScreenOcr.kt`）。

## 真机集成测试清单（PRD 10.2）

- [ ] 订单弹出后自动识别，1 秒内出结论
- [ ] 切到地图 / 其他应用后，悬浮提示立即消失，不读取其他应用文字
- [ ] 订单消失（接单 / 拒单 / 超时）后不再显示旧结论
- [ ] 同一订单不重复播报
- [ ] 识别不全时只说“订单信息不完整”，不给推荐
- [ ] 关闭无障碍权限后服务正常退出，悬浮提示消失
- [ ] 悬浮提示不遮挡接单按钮，不拦截触摸
- [ ] 运行一小时的耗电情况
